How to use a PDF tool

  1. Select the tool that matches your task.
  2. Read the tool page's instructions and choose a supported file.
  3. Upload the file and enter any requested options, such as a password or compression level.
  4. Wait for processing to finish, then review the result before using or sharing it.

Keep an original copy of important documents. PDF conversion may change formatting, scanned documents may require OCR, and repair tools cannot recover every damaged file.

Privacy and document safety

Before uploading confidential or sensitive documents, review our Privacy Policy and the information on the relevant tool page. Do not upload documents unless you are comfortable with the stated processing method. Use a strong, unique password when protecting a PDF, and store it somewhere safe.

Frequently asked questions

Are the PDF tools free?

The tools are offered for online use without creating an account. If a tool has specific limits, check the information shown on its page.

Do I need to install software?

You can open the website in a modern browser. Some tasks may be processed by the website's server, so the individual tool page explains how to use that feature.

Why did my PDF fail to process?

The file may be damaged, password-protected, unusually large, or contain features the tool does not support. Try a valid PDF and follow any error message. For password-protected files, use only a password you are authorised to use.

Will the result look exactly like the original?

Not always. Conversion, OCR, compression, and repair can affect formatting or content. Open the downloaded result and check important text, page order, tables, and images before sharing it.
